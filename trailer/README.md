# IndicMT trailer

A 70-second animated trailer for IndicMT, written in plain HTML, CSS and JavaScript. Open `index.html` in a browser and press **Play**, or press the space bar.

- `data.js`: every number shown on screen, taken from the evaluation results in this repository
- `trailer.js`: the animation; each frame is a function of the playback time, so the scrubber can jump to any point
- `trailer.css`: layout and the colour theme
- `music.mp3`: soundtrack

Keys: space plays or pauses, R restarts, H hides the time readout.
