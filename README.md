# IndicMT

Compact multilingual machine translation for English and the 22 Scheduled Indian languages.

IndicMT is a Transformer encoder-decoder trained from scratch on AI4Bharat's BPCC data, with one shared SentencePiece
vocabulary and target-language tags. It is converted to CTranslate2 for CPU serving.

Documentation is in progress.
